# QuizBox 题库格式合规标准

> **用途**：本文档是 QuizBox 导入解析器（`src/services/rule-parser.ts`）的**行为契约**。
> 任何 AI 协作者或人工整理者，照本规范改写「不合规题库」后，即可被解析器
> 100% 正确导入（题数完整、题型准确、答案对齐、选项不粘连）。
>
> **反向使用**：本文档列出的每条规则，都对应解析器里一段确定的成功/失败逻辑；
> 违反任意一条都会导致「丢题 / 误判题型 / 选项混乱 / 答案缺失」之一。

---

## 0. 一句话总则

> **一份合规题库 = 「每个大题区段有标题 + 每道题有题号 + 选项分行或规范拆分 + 答案紧跟本题」的纯文本。**

题库的「理想形态」长这样（这是解析器最容易吃准的格式）：

```
一、单选题
1.题干文本？
A.选项一
B.选项二
C.选项三
D.选项四
答案：A
2.第二题题干？
A.选项一
B.选项二
答案：B
二、判断题
1.陈述句，判断对错。
答案：对
```

下面逐条给出硬性要求与反面示例。

---

## 1. 文件格式

| 支持的格式 | 解析方式                    | 说明                                                     |
| ---------- | --------------------------- | -------------------------------------------------------- |
| `.docx`    | mammoth.js 转 HTML → 纯文本 | **推荐**。段落自动转行。                                 |
| `.md`      | 直接读文本                  | 等价于已是纯文本。                                       |
| `.pdf`     | 服务端 OCR                  | 仅用于扫描件，识别率取决于原文清晰度。                   |
| `.doc`     | ❌ 不支持                   | 旧二进制格式。请在 Word/WPS 里「另存为 .docx」后再导入。 |

**要求**：

- 必须以上表三种扩展名之一结尾；其他扩展名会被直接拒绝。
- `.doc` 必须先转 `.docx`，没有第二条路。

---

## 2. 大题区段标题（决定题型准确率，**强烈建议**）

解析器靠**区段标题**给区段内的题打上 `sectionType`（题型上下文）。有标题时，
缺答案的题也能正确归类；没有标题时，解析器只能靠选项/答案反推，容易误判。

### 合规的区段标题写法

标题行**单独成行**，以下任一形式都能被识别（正则见 `RE_SECTION_HEADER`）：

| 题型   | 合规标题示例                                               |
| ------ | ---------------------------------------------------------- |
| 单选题 | `单选题` / `一、单选题` / `一.单选题` / `单选题（共20题）` |
| 多选题 | `多选题` / `二、多选题` / `不定项选择题`                   |
| 判断题 | `判断题` / `三、判断题`                                    |
| 填空题 | `填空题`                                                   |
| 简答题 | `简答题`                                                   |
| 论述题 | `论述题`                                                   |

> 关键词：`单选`/`选择`→single、`多选`/`不定项选择`→multiple、`判断`→judge、
> `填空`→fill、`简答`→short、`论述`→essay。前缀的「一、」「二.」可有可无。

### ❌ 反面：无区段标题

```
1.题干
A.选项
答案：A
```

没有区段标题时，解析器能靠选项识别为选择题，但**判断题若写成「A.正确 B.错误」会被误判为单选题**（详见 §5）。务必加区段标题。

## 3. 题号（决定能否正确分块，**最关键**）

**这是最容易导致「整片题目被合并成一道」的坑。** 解析器主要靠题号切分新题。

### 合规的题号写法（任选其一）

```
1.题干        ← 数字 + 半角点
1、题干       ← 数字 + 顿号
1)题干        ← 数字 + 半角右括号
1．题干       ← 数字 + 全角点
(1)题干       ← 半角括号
（1）题干     ← 全角括号
[1]题干       ← 方括号
```

正则：`RE_QUESTION_NUM = /^[\s　]*[(\[（【]?(\d{1,4})[)\]）】]?[.、．)\s]/`

### 硬性要求

1. **每道题都要有题号**，即使题号不连续也行（`1`、`3`、`5` 也能各自成题）。
2. **题号在题干的行首**，前面最多有少量空白/全角空格。
3. **同一区段内题号建议连续**，但解析器不强求。

### ⚠️ 允许的例外：无题号的连续判断题

如果整个区段是判断题、且满足「题干 → 答案行」严格交替，解析器可用「答案行
作为分隔符」兜底切分。但**这是兜底逻辑，依赖严格的三行结构**：

```
判断题
1.第一题题干，以句号结尾。
A.正确 B.错误
答案：A
第二题题干，以句号结尾。       ← 没有题号也能被切出来（因上一行是答案行）
A.正确 B.错误
答案：B
```

> 触发条件：上一行命中 `isJudgeTerminatorLine`（即「对/错/正确/错误」单独成行，
> 或「答案：对/错/正确/错误/√/×/T/F/A/B」），且当前行是「以句末标点收尾的
> 完整陈述句」。**不满足条件时无题号的题会被合并丢失。**

### ❌ 反面（必改）：无题号且非判断题

```
单选题
题干一
A.x B.x C.x D.x
答案：A
题干二
A.x B.x C.x D.x
答案：B
```

→ 单选题/多选题/填空题**没有兜底分块**，「题干二」及之后会被全部合并进「题干一」，
**只产出 1 道畸形题**。必须补题号。

### ❌ 反面（必改）：题号被吞或非行首

```
第1题：题干      ← 「第」字开头，不匹配题号正则
题干（1）        ← 题号在题干中间而非行首
```

→ 无法识别为新题。改写成 `1.题干`。

## 4. 选项（决定选项能否正确拆出）

### 4.1 合规的选项写法（任选其一）

**最稳妥：每个选项单独一行。**

```
1.题干
A.选项一
B.选项二
C.选项三
D.选项四
```

**允许：同行多选项，但选项字母后必须有标点（`.`/`、`/`．`/`)`）。**

```
1.题干
A.选项一 B.选项二 C.选项三 D.选项四
```

正则 `RE_INLINE_OPT_SPLIT` 在「空格/句号/．」后遇到 `字母+标点` 时拆分。

**允许：同行无标点粘连（如 `A正确B错误` / `A观测法B考察法D实验法`）。**
解析器有宽松兜底 `splitInlineOptionsLoose`：行首是 `A`，且行内出现连续的
`B`/`C`/`D`（前一字符非英文字母）时拆分。但这种写法对解析器最不友好，
**建议尽量分行或加标点**。

### 4.2 选项字母要求

- 必须从 **A** 开始，按字母顺序连续（A、B、C、D…）。
- 大小写均可（`a.` 和 `A.` 等价）。
- 最多到 H（`RE_OPTION_HEAD` 允许 A–H）。
- **至少 2 个选项**，否则容易被当成非选择题。

### ❌ 反面（必改）：选项字母不连续或非 A 开头

```
1.题干
B.选项一       ← 不是从 A 开始
C.选项二
D.选项三
```

→ 解析器从 A 开始找，找不到 A 选项 → 选项数不足 → 可能误判题型。改成 A/B/C。

### ❌ 反面（必改）：选项夹在英文单词里

```
1.题干
AGBZ-1 标准规定…
```

→ `G`/`B`/`Z` 前后都是英文字母，不会被误判为选项标记（lookbehind 保护），
但若题干本身长这样，解析器会把整行当题干。这不算错，但答案字母可能对不上。

## 5. 判断题的特殊要求

判断题最容易和单选题混淆。**优先使用区段标题 `判断题`** 是最稳的。

### 答案写法（任选其一，都能被归一为 `T`/`F`）

| 写法                                                     | 归一结果                     |
| -------------------------------------------------------- | ---------------------------- |
| `答案：对` / `答案：正确` / `答案：√` / `答案：T`        | `T`                          |
| `答案：错` / `答案：错误` / `答案：×` / `答案：F`        | `F`                          |
| `对`（单独成行）                                         | `T`                          |
| `错：改错内容`                                           | `F` + 解析=改错内容          |
| `答案：A`（在**判断题区段**内，选项是「A.正确 B.错误」） | `T` 或 `F`（按选项语义映射） |

### 选项写法

判断题**可以没有选项**（最常见）：

```
1.陈述句。
答案：对
```

判断题**可以有「对/错」选项**（解析器会识别为 judge 而非 single）：

```
1.陈述句。
A.正确
B.不正确
答案：A
```

→ 选项内容全部命中 `RE_JUDGE_OPTION`（正确/错误/对/错/是/否/√/×/T/F）时，
即使写成 A/B 选项，也会被识别为**判断题**，并把字母答案映射回 T/F。

### ❌ 反面（必改）：判断题混在单选题区段里又无对错选项

```
单选题
1.陈述句。
A.选项一
B.选项二
答案：A
```

若这是判断题却放在「单选题」区段、且选项不是「对/错」词，解析器会忠实地把它
当成单选题。**题库整理者必须把判断题移到独立的「判断题」区段**，或把选项改成
`A.正确 / B.错误`。

## 6. 答案（决定答案能否对齐）

### 6.1 合规的答案写法

**答案单独一行，紧跟本题，以「答案」标记开头。**

```
1.题干
A.选项一
B.选项二
答案：A
```

答案标记正则（`RE_ANSWER`，大小写不敏感）：`答案`/`正确答案`/`参考答案`/`答`/
`Answer`/`answer`，后跟可选的 `:`或`：`。冒号可省略（`答案A` 也认）。

### 6.2 各题型答案的值

| 题型                    | 答案写法                                  | 归一化结果                  |
| ----------------------- | ----------------------------------------- | --------------------------- |
| 单选 single             | `A`                                       | `"A"`                       |
| 多选 multiple           | `ACD` / `A、C、D` / `AC`                  | `["A","C","D"]`（去重排序） |
| 判断 judge              | `对`/`正确`/`√`/`T` ↔ `错`/`错误`/`×`/`F` | `"T"` / `"F"`               |
| 填空 fill               | 见 §7                                     | `["空1","空2",...]`         |
| 简答 short / 论述 essay | 直接写文本                                | 原样保留                    |

### 6.3 文末集中答案（允许）

题目区不带答案、答案集中在文末时，解析器支持回填（`extractAnswerKey`）：

```
一、单选题
1.题干一
A.x
B.x
2.题干二
A.x
B.x

参考答案
1.A 2.B
```

或区间写法：

```
1-5 ABBAC
```

→ 展开为 1=A, 2=B, 3=B, 4=A, 5=C。

**硬性条件**：题号必须与答案表的编号对齐。各区段题号若都从 1 开始，答案区会
出现覆盖（后者覆盖前者）——**建议全卷题号连续，或答案区按区段分段标注**。

### ❌ 反面：答案缺冒号且非「答案」开头

```
正确选项是 A       ← 不被识别为答案行
选 A              ← 不被识别
```

→ 必须改写为 `答案：A`。

## 7. 填空题的空与答案

### 题干

用连续下划线 `__` 或空括号 `（）`/`()`标记空位：

```
1.人因工程学的研究包括____和____两个方面。
答案：理论研究、应用研究
```

`RE_BLANK = /_{2,}|（\s*）|\(\s*\)/`

### 答案分空规则（全系统统一约定，**重要**）

| 分隔符           | 语义                         | 示例                                          |
| ---------------- | ---------------------------- | --------------------------------------------- |
| `,` `，` 换行    | **分隔不同的空**             | `理论研究，应用研究` → 2 个空                 |
| `；`（中文分号） | **同一空的多个等价备选答案** | `红色；红色颜料` → 1 个空，判分时任一命中即对 |

> ⚠️ `；` 在全系统里**只用于「同一空的备选答案」**，不用于分空。
> 题库整理者若误用 `；` 分空，判分会把多空当成单空的多备选。

### 带前缀的填空答案（OCR 常见，允许）

```
第一空：红色
第二空：绿色
```

→ 按前缀归位到对应空位。

## 8. 解析（可选）

解析紧跟答案之后，以「解析」标记开头：

```
1.题干
A.x
B.x
答案：A
解析：因为 A 是正确的，所以选 A。
```

标记正则（`RE_ANALYSIS`）：`解析`/`详解`/`Explanation`/`explanation`，
后跟可选的 `:`/`：`。

判断题改错格式会自动把改错内容存为解析：

```
1.陈述句。
错：应改为「xxx」
```

→ 答案 `F`，解析 `应改为「xxx」`。

---

## 9. 水印与垃圾行（会自动过滤，但尽量剔除）

解析器会自动过滤：

- 重复 ≥ 2 次的短行（≤40 字、无句末标点）——典型广告水印。
- 含 `vx`/`微信`/`QQ`/`加V` 等联系方式的行。
- 纯分隔线（`===`/`---`/`___`/`●●●` 等连续符号 ≥3 个）。
- 过短无题号行（<6 字且无中文）。

**整理者无需手工清除水印**，但应确保**水印不要粘连到题干/选项行**（否则会被
当成题目内容的一部分）。

### ❌ 反面：水印与题干挤在同一行

```
1.题干（加微信xxxx获取完整版）
A.x
B.x
```

→ 括号内的水印会被并入题干。整理者应把水印单独提行。

## 10. 一份完整合规范例

```
一、单选题
1.人因工程学起源于哪个学科？
A.工程学
B.心理学
C.人体科学
D.以上都是
答案：D
解析：人因工程学是综合了工程学、心理学、人体科学等多学科的交叉学科。

2.下列哪个不是人因工程的研究内容？
A.人体特征
B.工作环境
C.股票分析
D.人机系统
答案：C

二、多选题
1.属于人因工程研究内容的有（）。
A.人体特征
B.工作环境
C.人机系统
D.股票分析
答案：ABC

三、判断题
1.人因工程学只研究机器，不研究人。
答案：错
解析：人因工程学的核心是研究人、机、环境三者的关系。

2.色彩能引起人的情绪变化。
A.正确
B.不正确
答案：A

四、填空题
1.人因工程学的研究包括____和____。
答案：理论研究，应用研究
```

## 11. 改写检查清单（交付前自查）

题库整理完成后，逐项打钩：

- [ ] 文件是 `.docx` / `.md` / `.pdf` 之一（不是 `.doc`）。
- [ ] 每个题型区段都有独立标题行（`单选题`/`多选题`/`判断题`/`填空题`/`简答题`/`论述题`）。
- [ ] **每道题都有题号**（除「判断题区段内严格三行交替」的兜底情形外）。
- [ ] 题号在行首，格式为 `1.` / `1、` / `1)` / `(1)` / `（1）` 之一。
- [ ] 选项从 A 开始、连续，每个选项单独一行（最稳）或字母后有标点。
- [ ] 判断题**要么在「判断题」区段内、要么选项是「对/错」词**，不要混在单选题区段。
- [ ] 答案以 `答案：`/`答案` 开头，单独成行，紧跟本题。
- [ ] 单选答案 1 个字母；多选答案多个字母；判断答案是对/错/√/×/T/F。
- [ ] 填空答案：`,`/`，`/换行 分空；`；` 只用于同一空的备选答案。
- [ ] 水印/联系方式不要粘连在题干或选项行里（最好整行删除或让其单独成行）。

全部打钩 → 可交付导入。
